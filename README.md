## Olá! Me chamo Heitor Morais 🧑🏽‍💻
**`Graduando em Ciência da Computação | Data Science & Software Development | Python • C • Java | Git • Github`**
###  Sobre mim

Sou estudante de Ciência da Computação na UNICAP (3º período), interessado por tecnologia e movido pela curiosidade. Aos 19 anos, foco minha formação no desenvolvimento de uma base lógica e técnica sólida para atuar na área de Ciência de Dados e Inteligência Artificial.

Ao longo da graduação e de cursos complementares, desenvolvi competências em diferentes ecossistemas:

- Python: Foco em análise de dados e automação (Imersão Dados Alura / Bootcamp Suzano).

- C e Java: Domínio de lógica de programação, estruturas de dados e conceitos de Programação Orientada a Objetos (POO).

- Inglês Intermeário: Atualmente cursando o nível Elementary (A2) no SENAC.

Embora esteja no início da minha jornada profissional, encaro cada desafio acadêmico e projeto pessoal com o máximo de compromisso.
Sou um entusiasta do aprendizado contínuo e acredito que a combinação entre disciplina acadêmica e prática constante é a chave para a inovação.
